# Astro Migration Source of Truth

This document is the implementation checklist and acceptance record for moving Bespoke Aviation from static HTML to Astro.

## Non-negotiable requirements

- Preserve the current design and content unless a change is documented here.
- Keep the `pre-astro` Git tag as the permanent record of the previous site.
- Build reusable components for repeated structures, not wrappers around every HTML element.
- Use semantic HTML, accessible controls, reduced-motion support, and keyboard navigation.
- Use a token-based CSS system for color, typography, spacing, layout, borders, and motion.
- Keep original photography as source assets and generate optimized formats during the Astro build.
- Do not mark a checklist item complete until its acceptance check passes.

## Target routes

| Current URL | Astro route |
| --- | --- |
| `/index.html` | `/` and `/index.html` |
| `/available-aircraft.html` | `/available-aircraft.html` |
| `/contact-us.html` | `/contact-us.html` |
| `/terms.html` | `/terms.html` |

Astro will use file-format output during migration so existing indexed and shared `.html` URLs remain valid.

## Intentional differences

- The legal page reads the preserved legal `<main>` from the pre-Astro HTML at build time to avoid copy drift.
- Existing MP4 video is retained; WebM encoding and source markup remain an optimization opportunity.
- The remote testimonial photograph remains external and is not yet handled by the Astro image pipeline.
